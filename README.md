# Next.XP Documentation

Reference documentation for [Next.XP](https://developer.enonic.com/docs/next.xp) — Enonic's integration between Next.js and Enonic XP, consisting of the `@enonic/nextjs-adapter` npm library, the `starter-nextjs` starter, and the `app-nextxp` XP application.

Documentation source is in `docs/`, written in AsciiDoc, and published to developer.enonic.com via the `enonic-docgen` GitHub Actions workflow.

The step-by-step tutorial and demo live in the [demo-nextjs](https://github.com/enonic/demo-nextjs) repo.
