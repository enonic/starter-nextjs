= Next.XP app
:toc: right
include::.variables.adoc[]

The Next.XP app is installed in Enonic XP and added to sites rendered by Next.js. It bridges Content Studio and the external front end; public visitors still access Next.js directly.

== Responsibilities

The app:

* Adds a site configuration field for selecting a named Next.js server
* Proxies Content Studio page and component preview requests
* Supplies render mode, project, base URL, and editor session context
* Rewrites proxied asset and application URLs for Content Studio
* Triggers Next.js revalidation after published content changes

Most implementation logic is supplied by the bundled `lib-nextxp` XP library. The app provides the installable application identity, site descriptors, configuration selector, and event subscription.

== Scope

The proxy accepts draft-branch editing traffic and rejects live-mode proxying. It is not intended to serve the public site. This separation allows the Next.js deployment and its CDN to handle visitor traffic normally.

The application ID is `com.enonic.app.nextxp`; its configuration file is `com.enonic.app.nextxp.cfg`.
