= Common API
:toc: right
include::../.variables.adoc[]

Exports from `@enonic/nextjs-adapter` may be used in shared code unless their behavior requires a server-only Next.js API.

== Usage

[source,TypeScript]
----
import {
    ComponentRegistry,
    getLocaleMapping,
    I18n,
    imageUrl,
    imageUrlQuery,
    validateData
} from '@enonic/nextjs-adapter';
----

== Functions

=== getContentBranch

Returns the XP branch for a request context: `master` for direct Next.js and `live` requests, `draft` for editing contexts.

[.lead]
Parameters

`getContentBranch()` takes an optional <<context,Context>> object. Without it, the branch follows the `RENDER_MODE` environment variable, defaulting to `master`.

[.lead]
Returns

`string` — `master` or `draft`.

=== getLocaleMapping

Resolves the locale, project, and site mapping for a request. The Content Studio project header takes precedence over the route locale.

[.lead]
Parameters

`getLocaleMapping()` takes a single <<context,Context>> object.

[.lead]
Returns

`LocaleMapping`.

=== getLocaleMappingByLocale

Returns the mapping for `locale`. The optional `useDefault` boolean defaults to `true` and controls fallback to the default mapping.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `locale` | `string` | *Optional.* Locale to find.
| `useDefault` | `boolean` | *Optional.* Fall back to the default mapping. Default: `true`.
|===

[.lead]
Returns

`LocaleMapping` or `undefined`.

=== getLocaleMappingByProjectId

Returns the mapping for an XP project ID. Matching is case-insensitive; `useDefault` defaults to `true`.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `projectId` | `string` | *Optional.* XP project ID to find.
| `useDefault` | `boolean` | *Optional.* Fall back to the default mapping. Default: `true`.
|===

[.lead]
Returns

`LocaleMapping` or `undefined`.

=== getRequestLocaleInfo

Returns `{locale, locales, defaultLocale}` for a request context. The project header is used in Content Studio; otherwise the route locale or default locale is used.

[.lead]
Parameters

`getRequestLocaleInfo()` takes a single <<context,Context>> object.

[.lead]
Returns

An object containing the selected `locale`, all configured `locales`, and `defaultLocale`.

=== localizeMappings

Prefixes the targets of URL mapping rules with a locale, for the `/api/mappings` response. Targets of the default mapping are returned unchanged, because default-locale URLs carry no prefix. Sources stay site-relative.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `mappings` | <<url-mapping-rule,UrlMappingRule>>`[]` | Rules to localize.
| `mapping` | `{locale, default}` | Locale mapping of the project, normally from `getLocaleMappingByProjectId()`.
|===

[.lead]
Returns

<<url-mapping-rule,UrlMappingRule>>`[]`.

[.lead]
Example

[source,TypeScript]
----
const MAPPINGS: UrlMappingRule[] = [
    {sources: ['/.*'], target: '/${siteRelativePath}'}
];

return NextResponse.json({mappings: localizeMappings(MAPPINGS, mapping)});
----

=== encryptParams

Encrypts a JSON-serializable object with AES-256-GCM, using the SHA-256 hash of `secret` as the key. The result is the `xp` blob format the Next.XP app sends. Requires Node.js `crypto`, so call it only from server code.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `params` | `Record<string, any>` | Values to encrypt.
| `secret` | `string` | Shared secret, normally `+ENONIC_API_TOKEN+`.
|===

[.lead]
Returns

`string` — base64url-encoded IV, ciphertext, and authentication tag.

=== decryptParams

Decrypts an `xp` blob produced by the Next.XP app or `encryptParams()`. Successful decryption proves that the sender knows the shared secret. Requires Node.js `crypto`, so call it only from server code.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `blob` | `string` | Value of the `xp` parameter.
| `secret` | `string` | Shared secret, normally `+ENONIC_API_TOKEN+`.
|===

[.lead]
Returns

`Record<string, any>` with the decrypted values, such as `xpProject`, or `null` when the blob is invalid or was encrypted with another secret.

=== imageUrlQuery

Returns the Guillotine selection for an image URL: `imageUrl(<args>)` with every field of the <<image-url,ImageUrl>> type. Use it inside a `... on media_Image` selection.

[.lead]
Parameters

`imageUrlQuery()` takes an optional `args` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `scale` | `string` | *Optional.* Image scale, for example `width(500)` or `block(100,100)`. Omit to use Guillotine's default.
| `quality` | `number` | *Optional.* JPEG quality.
| `background` | `string` | *Optional.* Background color for transparent images.
| `format` | `string` | *Optional.* Output format, for example `webp`.
| `filter` | `string` | *Optional.* Image filter.
|===

[.lead]
Returns

`string`.

[.lead]
Example

[source,TypeScript]
----
`... on media_Image { ${imageUrlQuery({scale: 'width(500)'})} }`
----

=== pageUrlQuery

Returns the Guillotine selection `pageUrl(<args>) { baseUrl path queryString }`.

[.lead]
Parameters

`pageUrlQuery()` takes an optional `args` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `params` | `Record<string, unknown>` | *Optional.* Extra query parameters added to the URL.
|===

[.lead]
Returns

`string`.

=== imageUrl

Builds an image URL from the result of `imageUrlQuery()`. For `meta.branch === 'draft'`, it appends the media endpoint path and query string to `/api/media`. For published content, it uses the media base URL (`+ENONIC_MEDIA_CDN+`, default `+ENONIC_API+`). See <<../nextjs/rich-text#media-proxy,Draft media proxy>>. Resolve the URL on the server and pass it to client components so the environment configuration stays server-side.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `data` | <<image-url,ImageUrl>> | URL object from Guillotine. Only `path` is required; `queryString` is optional. May be `null` or `undefined`.
| `meta` | <<media-url-meta,MediaUrlMeta>> | Branch context, usually the page's <<meta-data,MetaData>>.
|===

[.lead]
Returns

`string`, or `undefined` when `data` is empty.

=== mediaUrl

Builds a draft-proxy or published media URL from the result of `mediaUrlQuery()`, in the same way as `imageUrl()`.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `data` | <<attachment-url,AttachmentUrl>> | URL object from Guillotine. Only `path` is required; `queryString` is optional. May be `null` or `undefined`.
| `meta` | <<media-url-meta,MediaUrlMeta>> | Branch context, usually the page's <<meta-data,MetaData>>.
|===

[.lead]
Returns

`string`, or `undefined` when `data` is empty.

=== attachmentUrl

Builds a draft-proxy or published attachment URL from the result of `attachmentUrlQuery()`, in the same way as `imageUrl()`.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `data` | <<attachment-url,AttachmentUrl>> | URL object from Guillotine. Only `path` is required; `queryString` is optional. May be `null` or `undefined`.
| `meta` | <<media-url-meta,MediaUrlMeta>> | Branch context, usually the page's <<meta-data,MetaData>>.
|===

[.lead]
Returns

`string`, or `undefined` when `data` is empty.

=== pageUrl

Builds a relative Next.js URL from the result of `pageUrlQuery()`. The site-relative `path` is prefixed with `meta.locale` unless it equals `meta.defaultLocale`.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `data` | <<page-url,PageUrl>> | URL object from Guillotine. Only `path` is required, so `{path: '/'}` gives the site root. May be `null` or `undefined`.
| `meta` | `{locale, defaultLocale}` | Usually the page's <<meta-data,MetaData>>. Without `defaultLocale`, the locale prefix is always added, which gives the internal `/[locale]` route path.
|===

[.lead]
Returns

`string`, or `undefined` when `data` is empty.

[.lead]
Example

[source,tsx]
----
<Link href={pageUrl(parent.pageUrl, meta)}>Back</Link>
<Link href={pageUrl({path: '/'}, meta)}>Home</Link>
----

=== richTextQuery

Returns the selection for a rich-text field, including processed HTML and structured references for images, links, and registered macros. `fetchGuillotine()` appends the required fragment definitions automatically.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `fieldName` | `string` | Name of the rich-text field in the content or component schema.
| `options` | `object` | *Optional.* Image settings listed below.
|===

The optional `options` object has these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `imageWidths` | `number[]` | *Optional.* Responsive image widths. Default: `[400, 800, 1200]`.
| `imageSizes` | `string` | *Optional.* HTML sizes expression. Default: `(max-width: 400px) 400px, (max-width: 800px) 800px, 1200px`.
| `imageSrcWidth` | `number` | *Optional.* Primary image width. Omitted by default, leaving Guillotine's default in effect.
|===

[.lead]
Returns

`string`.

[.lead]
Example

[source,TypeScript]
----
const bodySelection = richTextQuery('body', {imageWidths: [640, 1280]});
----

=== richTextFragments

Returns the GraphQL fragment definitions spread by `richTextQuery()`, including the registered macros. `fetchGuillotine()` appends them automatically; use this function for queries sent through another client.

[.lead]
Returns

`string`.

Appends the rich-text fragment definitions a query spreads but does not define.

[.lead]

[.lead]

=== sanitizeGraphqlName

Converts text into a valid GraphQL name by replacing unsupported characters and prefixing names that begin with a number.

[.lead]
Parameters

`text` (`string`) — value to sanitize.

[.lead]
Returns

`string`.

=== validateData

Validates a `FetchContentResult`. Missing content invokes Next.js not-found handling; XP shortcuts invoke redirect handling.

[.lead]
Parameters

`props` (`FetchContentResult`) — result returned by `fetchContent()`.

[.lead]
Returns

`void`. The function may invoke Next.js navigation handling.

== Classes

=== ComponentRegistry

Static registry connecting XP descriptors to queries, processors, and React views.

==== addContentType

Registers a content-type mapping by application-qualified name.

==== addPage

Registers an XP page descriptor.

==== addLayout

Registers an XP layout descriptor.

==== addPart

Registers an XP part descriptor.

==== addMacro

Registers an XP macro descriptor.

==== addComponent

Registers a generic component kind such as the built-in `part`, `layout`, or `text` handling.

Each registration method accepts a name and a `ComponentDefinitionParams` object. Repeated registration merges properties for the same name.

==== setCommonQuery

Sets the query whose processed result is returned as `common` for every render.

==== getCommonQuery

Returns the registered shared query.

==== getByComponent

Resolves the definition for a normalized `PageComponent` from its type and descriptor.

==== getContentType

Returns a content-type definition by name, falling back to `+CATCH_ALL+` when registered.

==== getPage

Returns a page definition by descriptor, with catch-all fallback.

==== getLayout

Returns a layout definition by descriptor, with catch-all fallback.

==== getPart

Returns a part definition by descriptor, with catch-all fallback.

==== getMacro

Returns a macro definition by descriptor, with catch-all fallback.

==== getComponent

Returns a generic component-kind definition, with catch-all fallback.

==== getContentTypes

Returns all explicitly registered content-type definitions as name-definition pairs.

==== getPages

Returns all explicitly registered page definitions.

==== getLayouts

Returns all explicitly registered layout definitions.

==== getParts

Returns all explicitly registered part definitions.

==== getMacros

Returns all explicitly registered macro definitions.

==== getComponents

Returns all explicitly registered generic component definitions.

=== I18n

Static localization helper for server-rendered front-end phrases.

==== setLocale

Loads `@phrases/<locale>.json` and returns its dictionary.

==== localize

Returns the phrase for a key and substitutes positional `{}` or indexed `{0}` placeholders. A missing phrase is returned as `<key>`.

==== getLocale

Returns the active locale.

==== getDictionary

Returns the loaded phrase dictionary.

[#global-variables]
=== GlobalVariables

Variables the adapter supplies to every registered query. A variables function must return them, optionally with additional variables.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `path` | `string` | Full XP content path, including the site.
| `scopeKey` | `string` | Site path from the locale mapping.
| `project` | `string` | XP project from the locale mapping.
| `branch` | `string` | `draft` in draft mode, otherwise `master`.
|===

[#url-mapping-rule]
=== UrlMappingRule

One rule of the `/api/mappings` response.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `sources` | `string[]` | Conditions a content item must meet. A `field:value` entry compares a content field, for example `type:portal:site`; any other entry is a regular expression matched against the item's site-relative path.
| `target` | `string` | Next.js URL template. `+${siteRelativePath}+` is replaced by the item's site-relative path; other `+${field}+` placeholders are replaced by content field values.
| `matchAny` | `boolean` | *Optional.* Match when any source matches instead of all. Default: `false`.
|===

[#image-url]
=== ImageUrl

Result of `imageUrlQuery()`.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `path` | `string` | Full media API path with a leading slash.
| `queryString` | `string` | URL-escaped query string with a `?` prefix.
| `context` | `string` | Project context segment.
| `id` | `string` | Content ID.
| `fingerprint` | `string` | Media fingerprint.
| `scale` | `string` | Processed scale segment.
| `name` | `string` | File name, with the requested format extension.
|===

[#attachment-url]

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `intent` | `string` | `download` or `inline`.
|===

== Constants

[%header,cols="1,3"]
|===
| Export | Purpose

| `+APP_NAME+`, `+APP_NAME_DASHED+`, `+APP_NAME_UNDERSCORED+`
| Application key from the environment and descriptor-safe variants.

| `+IS_DEV_MODE+`
| Whether `NODE_ENV` is `development`, as under `next dev`.

| `+CATCH_ALL+`
| Registry key for a fallback definition.

| `+RENDER_MODE+`
| Direct, edit, preview, inline, live, and admin rendering modes.

| `+XP_COMPONENT_TYPE+`, `+XP_REQUEST_TYPE+`
| Normalized page-component kinds and fetch request kinds.

| `+FROM_XP_PARAM+`
| Name of the query parameter carrying the encrypted blob from XP: `xp`.

| `+RENDER_MODE_HEADER+`, `+PROJECT_ID_HEADER+`, `+XP_BASE_URL_HEADER+`, `+JSESSIONID_HEADER+`
| Header names used to pass rendering, project, and session context through the integration.

| `+PORTAL_COMPONENT_ATTRIBUTE+`, `+PORTAL_REGION_ATTRIBUTE+`
| DOM attributes used by Content Studio editing.

|===

Prefer these exports to duplicated string values in application code.
